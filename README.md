# 石匠 / SEKISHO ウェブサイト

神奈川県足柄上郡山北町の塗装専門店「石匠/SEKISHO」のモダンなウェブサイトです。

## 特徴

- **モダンなデザイン**: 洗練されたUI/UXデザイン
- **レスポンシブ対応**: スマートフォン、タブレット、PCすべてのデバイスに対応
- **スムーススクロール**: スムーズなページ遷移
- **アニメーション**: スクロール時のフェードインアニメーション
- **アクセシビリティ**: セマンティックHTMLと適切なコントラスト比

## ファイル構成

```
sekisho/
├── index.html      # メインHTMLファイル
├── styles.css      # スタイルシート
├── script.js       # JavaScriptファイル
└── README.md       # このファイル
```

## 使用方法

1. `index.html`をブラウザで開く
2. または、ローカルサーバーを起動:
   ```bash
   # Python 3の場合
   python -m http.server 8000
   
   # Node.jsの場合
   npx serve
   ```

## セクション

1. **ヒーローセクション**: メインビジュアルとCTA
2. **思い入れセクション**: 会社の理念と特徴
3. **コスト比較セクション**: 価格比較表
4. **お問い合わせセクション**: 連絡先情報とフォーム

## カスタマイズ

### 色の変更

`styles.css`の`:root`セクションでカラーパレットを変更できます:

```css
:root {
    --primary-color: #2c5f41;    /* メインカラー */
    --secondary-color: #d4a574;  /* アクセントカラー */
    --accent-color: #8b6f47;     /* 補助カラー */
}
```

### フォントの変更

Google Fontsから別のフォントを選択し、`index.html`の`<head>`セクションで変更できます。
